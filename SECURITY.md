## Current Support State

`1.0.0-rc.1` is a Published Release Candidate and a pre-release distributed through Packagist. There is no Published Stable release and no Stable support line. Publishing this RC does not establish Stable support.

## Reporting a Vulnerability

Please report suspected package vulnerabilities privately to [support@maatify.dev](mailto:support@maatify.dev). Do not report a vulnerability in a public issue.

Include the affected package or context, reproducible details, the potential impact, and the relevant environment, version, or commit when known. No response time is promised.

## Scope

This policy covers vulnerabilities in the package's I18n runtime and persistence behavior. Host authentication, authorization, deployment, and infrastructure defects belong with the owner of the relevant Host.
